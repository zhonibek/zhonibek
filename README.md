## Featured engineering work

### [IRAlib / Nationals](https://github.com/zhonibek/Nationals)

A VEX V5 robotics control project using C++, PROS, Eigen, and LemLib foundations. The repository includes trajectory tracking, localization, motor diagnostics, calibration routines, and a browser simulator.

- **Controls:** PID/feedforward, LQR and LTV-LQR modules, and quintic trajectory generation.
- **Localization:** odometry, extended Kalman filter, and particle-filter modules.
- **Engineering workflow:** interactive tuning routines, a tuning guide, and simulator validation scripts.

Start with the [robot entry point](https://github.com/zhonibek/Nationals/blob/main/src/main.cpp), [control subsystems](https://github.com/zhonibek/Nationals/tree/main/src/subsystems), and [simulator](https://github.com/zhonibek/Nationals/tree/main/simulator). This project builds on open-source libraries; their implementations and licenses are acknowledged in the repository.

### [PCMANai](https://github.com/zhonibek/AMD-software)

A Python system-telemetry and AI assistant prototype with a FastAPI backend and web dashboard. It explores a contextual-bandit agent with experience replay and local Qwen explanations. It includes Windows system-changing actions and needs an isolated environment for evaluation.

### [AETHER AI](https://github.com/zhonibek/My-Ai)

A Python and React application exploring local model inference, retrieval, streaming APIs, and model-provider integration. Built around FastAPI, PyTorch, and Hugging Face Transformers, with API and benchmark scripts in the repository.
